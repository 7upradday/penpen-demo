# PENPEN · 写信与收信一体化演示

在线演示：https://7upradday.github.io/penpen-demo/

完整流程：写信 → 投信 → 投递完成后约五秒自动吐出小狐狸信纸 → 点击信纸 → 信封展开、阅读示例回信 → 点击 × 收进月度信盒。首页也可直接打开「我的信盒」。

GitHub Pages 由 Actions 自动构建部署；推送到 main 后更新网站。原始附件、压缩包、测试截图及浏览器内的个人信件不上传。

运行：`npm run dev`，打开 http://localhost:4173/ 。构建：`npm run build`。

这是一套交互演示原型，未连接 AI 或远程存储。回信使用示例文案；草稿、已投递信件和月份收藏状态保存在当前浏览器，不会同步到其他设备。

- Blender 建模源文件：`assets/models/mailbox.blend`；浏览器模型：`assets/models/mailbox.glb`。建模脚本：`model-mailbox.py`。
- 信箱由真实网格、开槽、企鹅部件、光照和投影组成。单张参考图未提供背面与内部结构，这两部分为原型补全。
- 信封保持固定的几何尺寸，只进行平移和旋转，通过深度遮挡进入投信口。
- 写信区域为原生 textarea。圆形按键已连接实际输入；“中 / EN”切换本地拼音和英文，支持候选词、空格选词、删除及换行。设备原生中文组合输入不被拦截，移动端原生键盘弹出时隐藏站内键盘。
- 离线拼音词库来自 simple-ime 1.2.4（MIT，https://github.com/nieyuyao/simple-ime）。构建适配层仅提取词库查询引擎，不使用原包的全局输入框；版本升级时必须复核适配层。没有向远程接口发送输入内容。
- 写信正文统一使用霞鹜文楷完整版，覆盖 CJK 基本区与扩展 A 区，避免同一封信因为缺字混入另一套字体。字体以 OFL 1.1 授权随原型本地加载，不依赖网络字体服务。
- PENPEN 金属字杆接在真实正文变更上：英文输入与中文选词提交均触发击打回落，定位件跟随当前行位置；删除不触发击打，粘贴长文限制动效队列长度。减少动态效果设置下停用击打动画。
- 投递前验证本地保存是否成功。中文组合输入期间禁止提交，避免候选词尚未确认时提前发送。

已检查：构建、中文多行正文显示、Next 状态、投递完成状态、字体与模型资源加载。真机中文候选栏和软键盘高度仍需在目标手机验证。

## 小狐狸来信预览

首页“预览小狐狸来信”触发出信。信纸从原有信口匀速向下送出；使用原图贴在固定比例的三维平面上，信口裁切隐藏尚未送出的部分，不缩放拉伸纸张。动画约 4.7 秒，完成后点击纸张或“展开这封信”进入同伴版本的拆信、阅读与信盒收纳流程。

信纸资源为用户提供的 `04-fox-B-peek-panel.png`，本地保存为 `assets/letter-paper/fox.png`。这是空白主题信纸的交互演示，不生成回信正文，不触碰写信草稿。保留减少动态效果的系统偏好。
